# Internationalization

Agent Mesh localizes server user-facing strings and the Vue UI. Language is selected with the standard **`Accept-Language`** HTTP header.

## Server (`internal/i18n`)

- Locale catalogs are JSON files under [`internal/i18n/locales/`](../internal/i18n/locales/), embedded with `go:embed` (`en.json`, `zh-CN.json`, `ja.json`).
- Call sites use `i18n.T(lang, key)` or `i18n.Error(w, r, status, key)` so responses follow the request’s `Accept-Language`.
- Negotiation: first supported tag wins by quality (`q=`). Unsupported tags fall back to English. Prefixes map as `zh*` → `zh-CN`, `ja*` → `ja`, `en*` → `en`.
- CORS allow-headers on node/relay include `Accept-Language`.

Examples:

```http
Accept-Language: ja
Accept-Language: zh-CN,zh;q=0.9,en;q=0.8
```

Covered today: tray menu/balloon copy, and static HTTP error bodies (login, bad JSON, stream unsupported, and similar). Dynamic `err.Error()` strings stay English.

## Web UI

- Catalogs: `internal/relay/web/src/locales/{en,zh-CN,ja}.ts`.
- Preference cycles **system → en → zh-CN → ja** (Settings → Appearance). Stored as `mesh.locale` in `localStorage`.
- `fetchJSON` sets `Accept-Language` from the active UI locale so API errors match the page language.
